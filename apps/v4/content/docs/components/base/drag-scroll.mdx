## نصب

```bash
npx farsiui@latest add drag-scroll
```

## استفاده

```tsx showLineNumbers
import { DragScroll } from "@/components/ui/drag-scroll"

export function Example() {
  return (
    <DragScroll>
      <div className="flex w-max gap-2">{/* chips / cards */}</div>
    </DragScroll>
  )
}
```

روی موبایل اسکرول لمسی؛ روی دسکتاپ با کلیک‌نگه‌داشتن و کشیدن.
