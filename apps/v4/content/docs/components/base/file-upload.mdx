## نصب

```bash
npx farsiui@latest add file-upload
```

## استفاده

```tsx showLineNumbers
import { FileUpload } from "@/components/ui/file-upload"

export function Example() {
  return (
    <FileUpload
      accept="image/*,.pdf"
      maxSize={2 * 1024 * 1024}
      onValueChange={(files) => console.log(files)}
    />
  )
}
```
