## نصب

```bash
npx farsiui@latest add iran-division-picker
```

فایل‌ها داخل پوشهٔ `components/IranDivisionPicker` نصب می‌شوند.

## استفاده

```tsx showLineNumbers
"use client"

import { IranDivisionPicker } from "@/components/IranDivisionPicker/iran-division-picker"

export function IranDivisionPickerDemo() {
  return (
    <IranDivisionPicker
      onValueChange={(selection) => {
        console.log(selection)
      }}
    />
  )
}
```

یا مستقیم دموی آماده‌شده را ایمپورت کنید:

```tsx showLineNumbers
import { IranDivisionPickerDemo } from "@/components/IranDivisionPicker/iran-division-picker-demo"

export default function Page() {
  return <IranDivisionPickerDemo />
}
```

## سطوح قابل تنظیم

با `levels` مشخص کنید کدام سطوح نمایش داده شوند:

```tsx showLineNumbers
<IranDivisionPicker levels={["province", "county", "city"]} />
```

## مقدار خروجی

هر سطح انتخاب‌شده شامل `code`، `fullCode` و `name` است:

```tsx showLineNumbers
{
  province: { code: "23", fullCode: "23", name: "تهران" },
  county: { code: "01", fullCode: "2301", name: "تهران" },
  // ...
}
```

**نکته:** دادهٔ تقسیمات به‌صورت پیش‌فرض از `https://farsiui.ir/r/geo/iran` بارگذاری می‌شود؛ لازم نیست چیزی در پروژه کپی کنید. برای میزبانی خودتان از prop به نام `dataUrl` استفاده کنید.
