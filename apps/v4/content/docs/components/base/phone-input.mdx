## نصب

```bash
npx farsiui@latest add phone-input
```

## استفاده

```tsx showLineNumbers
import { PhoneInput } from "@/components/ui/phone-input"

export function Example() {
  return (
    <PhoneInput
      onValueChange={(digits, valid) => {
        console.log(digits, valid)
      }}
    />
  )
}
```

مقدار منطقی همیشه ۱۱ رقم ASCII به شکل `09xxxxxxxxx` است.
