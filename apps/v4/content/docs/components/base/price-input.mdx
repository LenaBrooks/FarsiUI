## نصب

```bash
npx farsiui@latest add price-input
```

## استفاده

```tsx showLineNumbers
import { PriceInput } from "@/components/ui/price-input"

export function Example() {
  return <PriceInput defaultValue="10000000" defaultCurrency="toman" />
}
```

زیر فیلد، مبلغ به حروف نمایش داده می‌شود؛ مثلاً `۱۰۰۰۰۰۰۰` → **ده میلیون تومان**. با سوییچ تومان/ریال مقدار با ضریب ۱۰ تبدیل می‌شود.
