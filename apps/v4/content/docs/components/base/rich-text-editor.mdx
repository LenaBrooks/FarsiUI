## نصب

این کامپوننت همان دموی زندهٔ سایت است (سبک **base-nova**). با `add`، خود ویرایشگر و وابستگی‌های UI آن (`button`، `toggle-group`، `dialog`، …) از **base-nova** نصب/به‌روز می‌شوند تا ظاهر دقیقاً مثل پیش‌نمایش بالا باشد — حتی اگر `components.json` هنوز روی `new-york-v4` باشد. برای تجربهٔ یکدست، `style` پروژه را `base-nova` بگذارید.

## استفاده

```tsx
import { RichTextEditor } from "@/components/ui/rich-text-editor"
```

```tsx
<RichTextEditor
  dir="rtl"
  lang="fa"
  placeholder="متن را بنویسید…"
/>
```

پیش‌فرض `variant="simple"` است: عنوان، درشت/مورب/زیرخط/خط‌خورده، فهرست، نقل‌قول، لینک، تصویر و واگرد. برای همهٔ امکانات از `variant="advanced"` استفاده کنید. هسته [Tiptap](https://tiptap.dev/) است و `dir="rtl"` / `lang="fa"` پیش‌فرض‌اند.

## کنترل‌شده

</div>

<DocsCollapsible title="کنترل‌شده">

با `value` و `onChange` محتوا را از والد کنترل کنید. `onChange` هم HTML و هم JSON Tiptap را برمی‌گرداند.

```tsx
const [value, setValue] = React.useState("<p>سلام</p>")

<RichTextEditor
  value={value}
  onChange={({ html }) => setValue(html)}
/>
```

</DocsCollapsible>

## امکانات نوار ابزار

</div>

<DocsCollapsible title="امکانات نوار ابزار">

در `variant="advanced"` ابزارهای پرتکرار در ردیف اول‌اند؛ با دکمهٔ سه‌نقطه در انتهای نوار، ردیف بعدی داخل همان نوار اضافه می‌شود (قلم، رنگ، جدول، …). تراز از راست‌چین شروع می‌شود.

</DocsCollapsible>

## تصویر و لینک

</div>

<DocsCollapsible title="تصویر و لینک">

لینک از نوار ابزار اضافه می‌شود؛ فقط `http://` و `https://` پذیرفته می‌شود. برای تصویر می‌توانید URL بدهید یا با `onUploadImage` فایل را آپلود کنید و نشانی برگردانید. خروجی HTML را قبل از `dangerouslySetInnerHTML` sanitize کنید.

</DocsCollapsible>
