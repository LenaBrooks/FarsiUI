## نصب

```bash
npx farsiui@latest add signature-pad
```

## استفاده

```tsx showLineNumbers
import { useRef } from "react"
import {
  SignaturePad,
  type SignaturePadHandle,
} from "@/components/ui/signature-pad"

export function Example() {
  const ref = useRef<SignaturePadHandle>(null)

  return (
    <SignaturePad
      ref={ref}
      onEnd={(png) => console.log(png)}
    />
  )
}
```

با `ref.current.toDataURL()` یا `toSvg()` خروجی بگیرید.
