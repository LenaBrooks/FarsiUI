## ببین الان کدام است؟

فایل `components.json` را در ریشهٔ پروژه باز کنید و مقدار `style` را بخوانید.

## عوضش کنید

در ریشهٔ پروژه این دستور را اجرا کنید:

```bash
npx farsiui@latest init
```

بعد به‌ترتیب:

1. بازنویسی `components.json` ← **yes**
2. نصب دوبارهٔ کامپوننت‌های UI ← **yes**
3. دیزاین سیستم دلخواه را انتخاب کنید (مثلاً **Aram**)

تمام. رنگ‌ها و فایل‌های `components/ui` با استایل جدید هماهنگ می‌شوند.

## یک خطی

برای **Aram**:

```bash
npx farsiui@latest init --preset Aram --force
```

اگر پرسید کامپوننت‌ها را دوباره نصب کند، **yes** بزنید.

نام‌هایی که در منو می‌بینید: **Default**، **Aram**، **Firoozeh**، **Rose**، **Nili**، **Khesht**.  
همان نام را در `--preset` هم می‌توانید بنویسید.
